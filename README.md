# Ducks Mod

![](https://raw.githubusercontent.com/Antarktidov/ducksmod/refs/heads/readme-and-license/readme-images/male_mallard.png)

Данный мод добавляет следующие разновоиднсоти уток:

* белая утка неизвестной породы
* кряква (самец и самка)
* мускусная (2 варианта)
* мандаринка
* каюга
* есть также отдельная текстура для моба утёнка (применяется к утятам всех уток, кроме каюги)

Скачать: https://github.com/Antarktidov/ducksmod/releases

Версия Minecraft: 1.21.1

Загрузчик модов: Forge
